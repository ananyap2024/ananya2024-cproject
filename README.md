# 📂 Basic Data Structure Algorithms

## 📌 Overview

This repository contains implementations of fundamental **data structures**, including different types of linked lists, queues, and stacks.
It serves as a **reference guide** for students, beginners, and anyone revising core data structure concepts.

---

## 📂 Project Structure

```
📁 basic-data-structures
│
├── LinkedList.java          # Implementation of a singly linked list
├── DoublyLinkedList.java    # Implementation of a doubly linked list
├── CircularLinkedList.java  # Implementation of a circular linked list
├── Queue.java               # Implementation of a queue (FIFO)
└── Stack.java               # Implementation of a stack (LIFO)
```
